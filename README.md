# ✨ Digital Mystery School

Welcome to the **Digital Mystery School** — an open-source sanctuary for modern mystics, esoteric technologists, and symbolic explorers. This interactive archive blends ancient wisdom with digital tools, inviting you to engage with the Hermetic, the mythic, and the unknown through your browser..

---

## 🛠️ Interactive Tools

| Tool | Description |
|------|-------------|
| `glyph-generator.html` | Generate symbolic glyphs for personal or mythic use |
| `ritual_card_generator.html` | Create ritual prompt cards for meditative or ceremonial practice |
| `symbol_dictionary.html` | Browse a living lexicon of esoteric symbols |
| `comparative_analysis_engine.html` | Contrast philosophical systems or symbolic roots |
| `hermetica.html` | Dive into a digital version of Hermetic writings |
| `hall_digital_archive.html` | Access a curated vault of esoteric documents and experiments |

> Additional files like `v1.html` through `v13.html` include raw prototypes and experiments.

---

## 🚀 Getting Started

You can run everything **locally** in your browser:

1. Clone the repo:
   ```bash
   git clone https://github.com/Lykon3/digital-mystery-school.git
   ```
2. Open any `.html` file in your browser.

No installation or compilation required. It’s pure front-end magic.

## 🔮 Contribution Guide

Want to contribute your own glyph generator, divination tool, or translation engine? Start here:

1. Fork the repo
2. Add your HTML/JS/CSS tool or improvement
3. Submit a pull request with a short description

All contributors are welcome, from code wizards to symbol poets.

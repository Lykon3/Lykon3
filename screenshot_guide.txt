# 📸 Screenshot Creation Guide

## Step 1: Take High-Quality Screenshots

### Tools Needed:
- **Browser**: Chrome or Firefox (for best rendering)
- **Resolution**: Set browser to 1920x1080 for crisp images
- **Extension**: "Full Page Screen Capture" or similar for scrolling pages

### What to Capture:

#### 1. Main Landing Page (index.html)
- **Full page** showing the title, tagline, and all 4 tool cards
- **Filename**: `landing-page.png`
- **Focus**: Beautiful mystical design with stars and gradient background

#### 2. Digital Hermetica (hermetica.html)  
- **Section showing**: Main title, Hall's portrait area, and some content
- **Filename**: `hermetica-demo.png`
- **Focus**: The scholarly layout and rich content

#### 3. Hermetic Lexicon (symbols.html)
- **Capture**: Symbol grid with some symbols visible + a modal open showing interpretation
- **Filename**: `symbols-demo.png` 
- **Focus**: Interactive symbols and the multi-tab interpretation system

#### 4. Living Glyph Generator (glyph-generator.html)
- **Show**: Generated glyph + Hall's interpretation panel
- **Filename**: `glyph-demo.png`
- **Focus**: The mystical generated symbol and AI interpretation

#### 5. Comparative Analysis Engine (analysis.html)
- **Display**: Concept selected + multiple thinker comparisons visible
- **Filename**: `analysis-demo.png`
- **Focus**: Side-by-side comparison interface

## Step 2: Optimize Images

### Recommended Settings:
- **Format**: PNG for crisp text, JPG for photos
- **Max width**: 800-1200px (GitHub will resize anyway)
- **Compression**: Use TinyPNG.com to reduce file size
- **File size**: Keep under 500KB each

## Step 3: Upload to GitHub

### Create folder structure:
```
digital-mystery-school/
├── assets/
│   └── screenshots/
│       ├── landing-page.png
│       ├── hermetica-demo.png
│       ├── symbols-demo.png
│       ├── glyph-demo.png
│       └── analysis-demo.png
```

### Upload Process:
1. Go to your repository
2. Click "Create new file"
3. Type `assets/screenshots/landing-page.png`
4. Upload your image file
5. Commit with message: "Add screenshots for README"
6. Repeat for each image

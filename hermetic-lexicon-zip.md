## 🚀 Installation Instructions

1. **Download the HTML file** from the artifact above
2. **Save as `symbols.html`** in your `/tools/` directory
3. **Update your main navigation** to link to `tools/symbols.html`
4. **Commit and push** to GitHub Pages

In your main `index.html`, update the Hermetic Lexicon link:
